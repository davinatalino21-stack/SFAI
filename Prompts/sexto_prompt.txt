# Prompt – Corrigir e tornar funcional a página de Configurações

Preciso que você faça uma **revisão completa da página de Configurações do site**, pois atualmente ela apresenta problemas de interação e navegação.

A página pode ser visualizada no print fornecido. **Não quero apenas alterações visuais:** é necessário verificar e corrigir a lógica e os eventos dos componentes para que as configurações realmente funcionem.

## 1. Corrigir o botão "← Voltar"

### Problema

O botão **"← Voltar"** aparece no topo da página de configurações, porém, quando clicado, **não retorna para a página anterior**.

### Correção

- Verificar como a navegação do projeto está implementada.
- Corrigir o evento do botão.
- Fazer com que ele retorne corretamente à tela anterior ou à página principal apropriada.
- Não utilizar um redirecionamento fixo que possa quebrar a navegação.
- Se o projeto utilizar React Router ou outro sistema de rotas, utilizar o mecanismo de navegação já existente no projeto.
- Garantir que o botão funcione tanto em desktop quanto em dispositivos móveis.
- Verificar se existem outros botões de voltar no projeto com o mesmo problema e, se houver, corrigir a causa de forma reutilizável.

# 2. Tornar os controles de configuração realmente interativos

Atualmente os controles da página parecem estar apenas sendo exibidos visualmente.

Verificar e tornar funcionais todas as opções disponíveis.

### Tema escuro

O switch de **"Tema escuro"** deve:

- responder ao clique/toque;
- alterar o tema da aplicação;
- atualizar visualmente o estado do switch;
- manter a configuração após mudar de página;
- se possível, persistir a preferência no `localStorage` ou no mecanismo de persistência já utilizado pelo projeto.

**Importante:** não implementar uma segunda lógica de tema se o projeto já possuir um sistema de tema. Reutilizar a implementação existente.

---

### Mostrar animação de digitação

O switch de **"Mostrar animação de digitação"** deve:

- ser clicável;
- possuir estado `ativado/desativado`;
- alterar efetivamente o comportamento do chatbot;
- manter a preferência salva.

---

### Enviar com Enter

O switch de **"Enviar com Enter"** deve:

- ser interativo;
- permitir ativar/desativar o envio da mensagem utilizando Enter;
- refletir corretamente o estado atual;
- alterar o comportamento do campo de mensagem do chatbot;
- preservar a possibilidade de utilizar `Shift + Enter` para quebra de linha, caso essa funcionalidade já exista.

---

### Salvar histórico automaticamente

O switch de **"Salvar histórico automaticamente"** deve:

- ser interativo;
- permitir ativar/desativar o salvamento automático;
- realmente alterar o comportamento do histórico;
- manter a preferência persistida.

# 3. Corrigir o botão "Limpar histórico do chat"

O elemento **"Limpar histórico do chat"** também deve ser funcional.

Ao clicar:

1. Solicitar confirmação ao usuário antes de apagar os dados.
2. Caso o usuário confirme, limpar o histórico de conversas.
3. Atualizar a interface imediatamente.
4. Garantir que as conversas realmente sejam removidas do mecanismo de armazenamento utilizado pelo projeto.
5. Caso o usuário cancele, não alterar nada.

Não apagar o histórico simplesmente ao clicar sem confirmação.
